# L's Trainlog

L's Trainlog is an Astro-based static blog deployed on Cloudflare Pages.

## About

This site collects posts and notes about:

- railways and public transport
- software and small web projects
- photography, travel, and observations along the way

You can also visit [BelloTreno](https://bellotreno.org), my railway project.

## Development

```bash
npm install
npm run dev
npm run build
npm run check
```

## Deployment

The site is built as a static Astro project and deployed on Cloudflare Pages.
